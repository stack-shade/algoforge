# AlgoForge Design System\n\nAlgoForge uses a **cute developer study-lab** visual language: technically credible, friendly enough to make practice feel approachable, and restrained enough to keep dense coding content readable.\n\n## Visual personality\n\n- Playful, not childish.\n- Soft rounded surfaces instead of hard dashboard rectangles.\n- Mint is the primary action color.\n- Lavender and pink are supporting accents.\n- Small monospace labels reinforce the engineering identity.\n- Micro-tilts, soft shadows and tiny spark details add personality without harming usability.\n- Dark mode remains deep and calm rather than pure black.\n\n## Color roles\n\n| Role | Purpose |\n| --- | --- |\n| Primary / Mint | Main actions, focus states, positive progress |\n| Lavender | Secondary emphasis and learning structure |\n| Pink | Small decorative moments and delight |\n| Background | Warm neutral in light mode; deep violet-black in dark mode |\n| Muted text | Supporting copy, metadata, helper labels |\n| Difficulty colors | Easy / Medium / Hard retain semantic green / amber / red |\n\nUse semantic variables from globals.css instead of introducing one-off colors in individual pages.\n\n## Shape language\n\n- Buttons: rounded-xl\n- Cards: rounded-2xl\n- Hero surfaces: up to rounded-[2rem]\n- Chips and status indicators: rounded-full\n- Prefer consistent 8px-ish spacing increments.\n- Avoid excessive nested borders.\n\n## Interaction language\n\nInteractive surfaces should communicate state through at least one of: background change, border emphasis, small elevation/translation, or a visible focus ring.\n\nHover motion stays subtle (1–3px) and respects prefers-reduced-motion.\n\n## Typography\n\n- Poppins: primary interface and educational copy.\n- JetBrains Mono: commands, metadata, labels and technical tokens.\n- Headings are bold with tight tracking.\n- Body text uses generous line-height for dense explanations.\n\n## Component rules\n\n### Buttons\n\nPrimary actions use the mint semantic primary token, rounded corners and a restrained glow. Secondary actions use outline or secondary surfaces.\n\n### Cards\n\nCards use the semantic card surface, a soft ring, generous radius and a small hover elevation. Large content groups should use bento-like compositions instead of uniform grids where possible.\n\n### Navigation\n\nDesktop navigation stays compact and pill-shaped. Mobile navigation is grouped into a single obvious menu. Search and progress should remain easy to reach.\n\n### Hero sections\n\nA hero should explain what AlgoForge is, who it is for, the first action, and one concrete preview of the learning experience.\n\nAvoid hero layouts that spend the first viewport on abstract branding without showing the product.\n\n### Cute details\n\nUse tiny stars, hearts, chips, micro labels and slight rotation sparingly. Decorative elements must never compete with headings, controls or problem content.\n\n## Accessibility guardrails\n\n- Keep focus rings visible.\n- Do not rely on color alone for difficulty or state.\n- Maintain readable text contrast.\n- Respect reduced-motion preferences.\n- Keep interactive targets comfortably tappable on mobile.
